# CodeAlpha Machine Learning Internship Projects

This repository contains the machine learning projects developed as part of the **CodeAlpha Machine Learning Internship Program**.

## Projects Included

### 1. Handwritten Text Recognition Using Deep Learning

A deep learning-based Handwritten Text Recognition (HTR) system that converts handwritten text images into editable digital text.

#### Key Features

* CRNN (CNN + BiLSTM + CTC) architecture
* Custom image preprocessing pipeline
* Handwriting region detection and cropping
* Real-time prediction through Streamlit
* Confidence score generation
* Downloadable text output

#### Technologies Used

* Python
* PyTorch
* OpenCV
* Streamlit
* Hugging Face Datasets

#### Project Folder

```text
CodeAlpha_HandwrittenTextRecognition/
```

### 2. Heart Disease Prediction System

A machine learning system that predicts the likelihood of heart disease using patient medical data and classification algorithms.

#### Key Features

* Exploratory Data Analysis (EDA)
* Multiple model training and comparison
* Hyperparameter tuning using GridSearchCV
* Risk probability prediction
* Interactive Streamlit dashboard
* Model evaluation using multiple metrics

#### Technologies Used

* Python
* Scikit-learn
* XGBoost
* Pandas
* NumPy
* Streamlit

#### Project Folder

```text
CodeAlpha_HeartDiseasePrediction/
```
